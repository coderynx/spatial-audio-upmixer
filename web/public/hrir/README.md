# Spatial Audio Engine decode filters

`flat_o3_decode_*.wav`, `studio_o3_decode_*.wav`, `listening_o3_decode_*.wav`
— order-3 (16 ACN channel × {L, R} = 32-filter) ambisonic-to-binaural decode
banks for the three Spatial Audio Engine profiles (Studio/Listening/Flat).
Each set is split into four 8-channel WAVs (`_01-08ch`, `_09-16ch`,
`_17-24ch`, `_25-32ch`) because browsers cap multichannel WAV decode at 8
channels; `useStemPreview.ts`'s `fetchDecodeFilterChannels` fetches and
concatenates all four at runtime.

Generated by `scripts/build_binaural_filters.py` from a parametric
spherical-head HRTF model (not a measured dataset) plus a synthesized room
tail for Studio/Listening. These files are byte-identical to
`upmixer/binaural/hrir/` — regenerate both together by re-running the build
script, never hand-edit one side.

Full contract (signal graph, channel-order convention, per-profile
parameters): `docs/standards/spatial_audio_engine.md`.
