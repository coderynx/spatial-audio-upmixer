# upmixer web client

React and shadcn/ui client for the upmixer web application. Talks to [`apps/api`](../api) over `/api/*`; contains
no processing logic of its own.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:5173`. The dev server proxies `/api` to `http://127.0.0.1:8000` (see `vite.config.ts`), so
run `apps/api`'s `upmixer-web` alongside it.

## Build

```bash
npm run build   # tsc -b && vite build, output to dist/
npm run lint
npm test        # vitest run
```

Point `apps/api`'s `UPMIXER_FRONTEND_DIR` at the built `dist/` directory to have the API serve this client as a
static SPA.

## Layout

- `src/` — app shell (`main.tsx`, `App.tsx`, `api.ts`, `theme.tsx`), `features/` (composer, jobs, projects),
  `components/`, `lib/`. Tests are colocated (`*.test.ts(x)`) rather than under a separate `tests/` directory.
- `public/` — static filter assets consumed by the browser preview (`hrir/`, `xtc/`, `eq_fir/`), regenerated by the
  root `scripts/build_*_filters.py` tools.
- `scripts/` — `render-preview-golden.mjs` (bundles the preview graph and renders the cross-engine golden fixture).

See [Web UI design specification](../../docs/web_ui_design.md) and [Web architecture](../../docs/web_architecture.md)
before adding a page, control, or visual state.
