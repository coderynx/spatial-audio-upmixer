# Spatial Audio Engine decode filters

`{profile}_o3_decode_{layout_slug}_*.wav` — order-3 (16 ACN channels × L/R =
32-filter) ambisonic-to-binaural decode banks for profiles `flat`, `studio`,
and `listening`, and layouts `stereo`, `5.1`, `7.1`, `5.1.2`, `5.1.4`,
`7.1.2`, and `7.1.4`. Dots in a layout name become underscores in the asset
name. Each set is split into four
8-channel WAVs (`_01-08ch`, `_09-16ch`, `_17-24ch`, `_25-32ch`) because
browsers cap multichannel WAV decode at 8 channels.

The original profile-only names remain as measured union-direction compatibility
banks for callers that have no layout; the preview uses the layout suffix when
one is known.

Generated by `scripts/build_binaural_filters.py` from measured SADIE II D1/KU100
48 kHz diffuse-field-compensated HRIRs. `flat` is anechoic; Studio/Listening
append a short, low-level deterministic early-ambience tail. The files are byte-identical to
`packages/core/src/binaural/hrir/`; regenerate both locations together and
never hand-edit one side.

Source, license, and generation details: `docs/standards/measured_hrir_provenance.md`.
